# Security Policy

## Supported Versions

Security fixes are provided for the latest code on the `main` branch.

## Reporting a Vulnerability

Please do not open a public issue for a suspected security vulnerability. Use the repository's private GitHub Security Advisory reporting flow instead:

https://github.com/akshar2324/Wallpaper_Engine/security/advisories/new

Include a clear description, reproduction steps, affected Android versions, and any proof of concept. Reports will be acknowledged as soon as possible and handled privately until a fix is available.
