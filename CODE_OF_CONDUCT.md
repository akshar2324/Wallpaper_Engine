# Code of Conduct

## Our Standard

Contributors are expected to be respectful, constructive, and welcoming. Harassment, personal attacks, discrimination, and deliberately disruptive behavior are not acceptable.

## Scope

This applies to project spaces, issues, pull requests, reviews, and direct project communication.

## Enforcement

Report conduct concerns privately through the repository's GitHub Security Advisory flow. Project maintainers may remove content, reject contributions, or restrict participation when this standard is violated.
